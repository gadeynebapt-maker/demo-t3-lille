# T3 rénové à Lille — visite 3D KODEO

Démo de visite 3D libre : un T3 de 63 m² au 2e étage d'un immeuble en brique rénové, à Lille (bien fictif).
Façade, entrée dans l'appartement, vue éclatée, surfaces des pièces, visite guidée.

Réalisé par KODEO avec Blender (Cycles) et three.js. Textures et modèles Poly Haven et ambientCG (CC0).
